# Q5 Flowchart

Faça um programa em java e seu respectivo fluxograma que dada uma distancia em km converta e exiba em milhas, onde 1Milha = 1,60934km

## Converter distâncias de Km para Milhas

```mermaid
graph LR
    A([Inicio]) --> B[km, milhas]
    B --> C[/km/]
    C --> D["milhas=km/1,60934"]
    D --> E[/milhas/]
    E --> F([Fim])
```
